# Compose CLI 🚀

**A terminal-first CLI tool for Android developers** who live in the command line, making it effortless to create, manage, and launch Jetpack Compose projects.

---

## Features ✨

- **`init`** – Quickly create a new Jetpack Compose project with a clean, ready-to-code structure.  
- **`sync`** – Sync dependencies and ensure your project is up-to-date.  
- **`run`** – Assemble, install, and launch your app on a selected Android device or emulator. Includes real-time logging to help you debug faster.  
- **`launcher`** – Generate app icons for your projects with ease.

---

## Installation 🛠

```bash
yay -S compose-cli-bin
```
